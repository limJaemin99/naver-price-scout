네이버 쇼핑 최저가 일괄 조회 도구

품목 리스트 엑셀을 올리면 각 상품의 최저가를 자동 조회하고 확정 / 확인필요 / 검색결과없음으로 분류합니다.

⚠️ 이 페이지를 파일로 직접 열었습니다(file://). 네이버 API는 브라우저 직접 호출을 CORS로 막습니다. 프로젝트 폴더에서 node server.js 실행 후 http://localhost:3000 으로 접속하세요.
⏸ 진행 중이던 조회 작업이 있습니다 ().

1. 네이버 검색 API 키 설정

발급받은 Client ID / Secret 을 입력하고 연결 테스트로 정상 작동을 확인하세요. 키는 이 브라우저(localStorage)에만 저장되며 서버로 저장·전송되지 않습니다.

2. 품목 리스트 업로드

엑셀(.xlsx)을 올리면 시트·헤더·컬럼을 자동 감지합니다. 감지 결과가 틀리면 드롭다운으로 교정하세요.

3. 검색어 미리보기

품명에서 관리코드 괄호를 제거해 검색어를 생성했습니다. 각 검색어는 직접 수정할 수 있고, 수정 내역은 이 브라우저에 품명 기준으로 저장되어 같은 파일을 다시 올릴 때 자동 적용됩니다.

# 원본 품명 생성된 검색어 (수정 가능)

4. 실행 — 최저가 조회

최종 검색어를 순차로 조회해 결과를 이 브라우저(IndexedDB)에 캐시합니다. 판정은 다음 단계에서 수행하며, 캐시 덕분에 임계값을 바꿔도 API 재호출 없이 재판정할 수 있습니다.

5. 결과 확인 — 판정

캐시된 검색 결과를 판정 규칙으로 분류합니다(API 재호출 없음). 확인필요는 사유와 함께 표시되니, 링크로 직접 확인 후 판단하세요. 애매하면 확정하지 않고 확인필요로 남깁니다.

6. 다운로드

판정 결과를 엑셀 2종으로 내려받습니다. 두 파일 모두 오른쪽에 검색어·최저가·판매처·상품링크·판정·사유·감지용량·배송비(수동입력)·조회일시 컬럼이 추가되고, 행 배경색으로 판정을 구분합니다(확정/확인필요/검색결과없음). 배송비는 링크로 확인 후 직접 입력하는 빈 칸입니다.

① 결과_원본형.xlsx

업로드한 원본의 모든 행(선택 브랜드, 재고 로트 중복 포함)을 그대로 두고 결과 컬럼을 추가.

② 결과_보고서형.xlsx

품명 단위로 병합(유통기한 임박·재고 합계·공급가 최솟값)하고 카테고리별로 정리한 보고 포맷.
