네이버 쇼핑 최저가 일괄 조회 도구

품목 리스트 엑셀을 올리면 각 상품의 최저가를 자동 조회하고 확정 / 확인필요 / 검색결과없음으로 분류합니다.

⚠️ 이 페이지를 파일로 직접 열었습니다(file://). 네이버 API는 브라우저 직접 호출을 CORS로 막습니다. 프로젝트 폴더에서 node server.js 실행 후 http://localhost:3000 으로 접속하세요.

1. 네이버 검색 API 키 설정

발급받은 Client ID / Secret 을 입력하고 연결 테스트로 정상 작동을 확인하세요. 키는 이 브라우저(localStorage)에만 저장되며 서버로 저장·전송되지 않습니다.

2. 품목 리스트 업로드

엑셀(.xlsx)을 올리면 시트·헤더·컬럼을 자동 감지합니다. 감지 결과가 틀리면 드롭다운으로 교정하세요.
